# ProjetoSiteMusica
Atividade - Criação de Site de Tema Livre

Alunos MAURÍCIO ALVES DE BARROS NETO e RAPHAEL LEON RAMOS DA SILVA

Professor CHESSMAN KENNEDY FARIA CORREA

Disciplina DESENVOLVIMENTO WEB E IHC

Orientações

• Criar um site contendo pelo menos 5 páginas e com navegação, sobre qualquer assunto. Tema livre.

• O site deve conter as seguintes mídias: texto (blocos contendo texto com significado), imagem, áudio e vídeo.

• O site deve ser criado apenas com as seguintes tecnologias: HTML, CSS e Javascript.

• O site deve conter recursos CSS e ações executadas com Javascript.

• Pelo menos uma das mídias (imagem, gráfico, áudio ou vídeo) deve ser de autoria própria.

• O trabalho deve ser feito individualmente ou em dupla.

Critérios de Avaliação

• Site com 5 páginas (5 arquivos de HTML diferentes) - 1 ponto

• Navegação - 1 ponto

• Texto (blocos de texto com significado) - 1 ponto

• Imagem - 1 ponto

• Vídeo - 1 ponto

• Áudio - 1 ponto

• Organização e qualidade visual do site - 1 ponto

• Uso de javascript – 1 ponto.

• Imagem, gráfico, vídeo ou áudio de produção própria (deve ser necessário explicar como a mídia foi criada). 2 pontos.

• ATENÇÃO. O uso de alguma tecnologia que não seja HTML, CSS e Javascript resultará em um desconto de 4 pontos.

Projeto elaborado por alunos da Unifeso — Centro Universitário Serra dos Órgãos.
